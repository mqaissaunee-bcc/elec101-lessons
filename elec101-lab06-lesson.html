Section 6.1

Series, parallel and series-parallel

How to recognise each arrangement by tracing the paths current can take.

Every circuit you draw from now on is built from two basic ways of connecting parts: series and parallel. Most real circuits mix the two, which makes them series-parallel. You don't need to do calculations in this course, but you do need to recognise each arrangement, because the lab tasks say things like "place R3 in series with R2".

Follow the current

The easiest test is to trace every path current can take from the + terminal of the source back to the − terminal.

  • Only one path? Every part on it is in series, and they all carry the same current.
  • The path splits? The separate routes are branches. Parts on different branches between the same two nodes are in parallel, and they all have the same voltage across them.
  • A part on every path is in series with the rest of the circuit.

Section 6.2

Input, output, ground and netlists

Finding the input and output nodes, and how net aliases name them.

To describe what a circuit does, you need to know where the signal goes in, where you measure it, and what everything is measured from. That's the job of the input node, the output node and ground.

Finding the input and output

The handout's method works for any circuit:

  1. Find the node shared by the input part (usually the source) and the output part. That's the natural place for ground.
  2. Stand at ground and look through the input part. The node on its other side is the input node.
  3. Stand at ground and look through the output part. The node on its other side is the output node.

Try it on Lab 6A's circuit, where VS is the input part and R2 is the output part.

Choose a node to highlight it.

Naming nodes: net aliases and the netlist

Q Circuits turns your drawing into a netlist: one line per part, listing the nodes it connects to and its value. You can read it in the Netlist panel. Ground is always node 0. Other nodes get a net alias name if you placed one, or a number if you didn't.









Reading a line: R1 A B 100 means "R1 connects node A to node B and is 100 Ω". The source line lists its + node first. The panel also shows a title line and the analysis command, and your node numbers may differ from the ones here.


Why names help. Numbers are handed out by the program and can change whenever you rewire. A name like OUT stays put, so plots, probes and checks that refer to it keep working. The Lab 6 checks look for your aliases by name.

Estimate before you simulate


Work from the far end back toward the source:


    

  • R2 and R3 in series: 600 + 600 = 1,200 Ω.
    • 

  • That 1,200 Ω branch in parallel with R4 (also 1,200 Ω): two equal resistors in parallel make half, 600 Ω.
    • 

  • Add R1 in series: 100 + 600 = 700 Ω in total.
    • 

  • The middle node sits across the 600 Ω part of that 700 Ω total, so it gets 600 ÷ 700 of the 12 V.
    • 

  • R2 and R3 are equal, so OUT is half of the middle node's voltage.
    • 







Predict first. Use the steps above to work out the voltage at OUT, in volts.









  1. Middle node: 12 × 600 ÷ 700 = 10.29 V.
  2. OUT: half of that, 10.29 ÷ 2 = 5.14 V.
  3. Check: the current from the source is 12 ÷ 700 = 17.1 mA, and R1 drops 17.1 mA × 100 Ω = 1.71 V, leaving 10.29 V at the middle node.




Section 6.6
Lab 6C: crossovers and power symbols
Draw a differential pair with split supplies and a wire crossing.




Open 6C · Draw a differential pair with crossovers. This is the busiest drawing so far: two transistors, a split power supply, and a wire that has to cross another without connecting. You won't simulate it; the lab checks that it's drawn and connected correctly.


What the circuit is


It's a differential amplifier, a building block inside every op amp. Q1 and Q2 share the emitter resistor REE, so they compare their two base voltages: Q1's base receives the input signal, and Q2's base is held at ground. You'll analyse amplifiers in Lab 12; for now the goal is a clean, correct drawing.


New ideas in this drawing






Power symbols
Tool: Power symbol (P)


A T-shaped symbol with a name. Every symbol with the same name is the same node, so VCC and VEE reach every part that needs them without long wires.
More about power symbols
The handout calls this part VCC_BAR. Press O twice before placing a VEE symbol so its bar points down, the convention for a negative supply.
  • Use them for supplies that connect to many places.
  • Check the spelling carefully: a symbol named VCC1 is a different node from VCC.


Crossover
Wires that cross without connecting


Q2's base wire has to pass Q1's emitter lead. Keep drawing past it: no dot means no connection.
More about crossovers
A dot at a crossing would join Q2's base to the emitters and change the circuit completely. In Q Circuits a wire only connects where one of its ends lands on a pin or wire, so a straight wire drawn across another never joins it.


AC test source
Toolbar: V, DC 0, AC magnitude 1


The input signal source, used for AC sweeps. PSpice has two sine sources: VAC (1Vac, 0Vdc) for AC sweeps and VSIN for transient runs.
More about the two AC sources
  • For an AC sweep: set DC 0 and AC magnitude 1. The simulator varies the frequency.
  • For a transient run: set the value to SIN(offset amplitude frequency), as in Lab 5B.


Q2N2222 transistor
Toolbar: NPN, model Q2N2222


A general-purpose NPN transistor. Choose the model in the Selected part panel.
More about transistor models
A model is a list of numbers describing how a real part behaves: how much it amplifies, its capacitances, and so on. The PSpice handout has you edit the Q2N2222 model and add your name to it; in Q Circuits you just choose the model, because the simulator already has it.

Glossary


Dotted-underlined words in the lesson show their definition when you point at, tap or tab to them. The full course glossary (opens in a new tab) is searchable.




Series
One path; the same current through every part.


Parallel
Parts across the same two nodes; the same voltage across each.


Branch
One of the separate paths in a parallel circuit.


Series-parallel
A mix of series and parallel connections.


Input node / output node
The nodes on the far side of the input and output parts, looking from ground.


Net alias
A name on a wire that labels, and connects, a node.


Netlist
The text list of parts and nodes that the simulator reads.


Floating node
A node with no DC path to ground.


Power symbol
A named supply connection; same name, same node.


Crossover
Two wires that cross without connecting.


Differential amplifier
A two-transistor stage that responds to the difference between its inputs.
