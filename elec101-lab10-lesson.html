Section 10.1

Digital logic basics

Bits, logic levels and the states a digital simulation can show.

Labs 4 to 9 were analog: voltages could take any value. From Lab 10 on you'll simulate digital circuits, the building blocks of computers, where each signal is only ever one of two values.

Bits and logic levels

A bit is a single binary digit, 0 or 1. What it means is up to the designer: off/on, false/true, no/yes. Real circuits use voltages to stand for bits; the 7400-series TTL chips in this lab treat about 0 V as 0 and 5 V as 1. Q Circuits does the same, with the dividing line at 2.5 V, so each signal is a clean logic level.

Logic states you may see in a simulation
StateMeaning
0Low, false, no, off
1High, true, yes, on
RRising: changing from 0 to 1 during this interval (PSpice)
FFalling: changing from 1 to 0 during this interval (PSpice)
XUnknown state (X): could be high, low or in between (you'll meet it in Lab 11)
ZHigh impedance: the output isn't driving the wire at all (PSpice)

Why digital?

  • Noise doesn't matter much. 4.6 V and 4.9 V both read as 1, so small disturbances don't change the answer.
  • It combines. A few simple rules, the logic gates, build up into adders, memories and whole processors.
  • It's what computers do. Every number, letter and image in a computer is stored as bits.

What Lab 10 covers

You'll drive single 7400-series gates with digital stimulus sources, watch the results as a timing diagram, and turn each diagram into a truth table. Every circuit in this lab is combinational logic: the output depends only on the inputs right now.

Section 10.2

Logic gates

NOT, AND, NAND, OR, NOR and XOR, with a playground to try each.

A logic gate takes one or more 0/1 inputs and produces a 0/1 output by a fixed rule. The rule is described three ways: in words, as a Boolean expression, and as a truth table listing the output for every input combination.

Inverter

7404

The output is the opposite of the input. Q = NOT A

More about Inverter

Also called complementation or negation. A small circle (bubble) on any symbol means “invert here”.

AND

7408 (2-input), 7411 (3-input)

The output is 1 only when every input is 1. Q = A · B

More about AND

Think of switches in series: the lamp lights only if all are closed.

NAND (NOT AND)

7400 (2-input), 7410 (3-input)

The output is 0 only when every input is 1. Q = NOT (A · B)

More about NAND

An AND followed by a NOT. NAND gates alone can build any logic circuit, which makes them the workhorse of digital design.

OR

7432

The output is 1 when any input is 1. Q = A + B

More about OR

Think of switches in parallel: any closed switch lights the lamp. The + means OR here, not addition.

NOR (NOT OR)

7402

The output is 1 only when every input is 0. Q = NOT (A + B)

More about NOR

An OR followed by a NOT. Like NAND, NOR alone can build any logic circuit.

XOR (exclusive OR)

7486

The output is 1 when the inputs differ. Q = A ⊕ B

More about XOR

Used to compare bits and in adders. You'll use it in Lab 11A.

Truth table

Reading a truth table

  • Each row is one combination of inputs. Two inputs give 4 rows; three give 8. Each extra input doubles the count.
  • Rows are listed in binary counting order: 00, 01, 10, 11. That way no combination is missed.
  • The output column is the gate's whole personality. Two circuits with the same output column do the same job, however they're built.

Names like U1A

A 7432 chip contains four OR gates. On a schematic the chip is U1, and its gates are U1A, U1B, U1C and U1D. A second chip would be U2, and so on. In Lab 10 you only use the first gate of each chip.

The Digital parts in Q Circuits

  • The parts palette has Analog and Digital tabs. Opening a Lab 10 or 11 exercise switches to Digital. Keyboard shortcuts reach every part from either tab.
  • Gate (2 inputs) and Gate3 (3 inputs) have a Device field in the Selected part panel. Choosing the part number sets the logic function and redraws the symbol.
  • NOT is the 7404 inverter; STIM1 is the digital stimulus (next section).
  • No ground symbol is needed for an all-digital circuit: as the handout says, digital parts have their power and ground built in. A circuit with analog parts still needs one.
  • Inside the simulator, each gate reacts to its inputs about 10 nanoseconds later, like a real chip. At the millisecond scale of this lab, that's too short to see.

Section 10.4

Digital stimuli and timing diagrams

STIM1 commands, the handout's tables, and logic lanes.

A digital circuit needs digital inputs. The STIM1 part (a digital stimulus) produces a list of logic levels at set times.

Commands: time, then level

In PSpice each step is a separate COMMAND1, COMMAND2 … property. In Q Circuits you type them all in the Commands field, separated by semicolons:

0s 0; 1m 1; 2m 0; 3m 1

  • Each pair is a time (from the start of the run) and the level from then on.
  • Keep the m: 1m is 1 ms, but 1 alone is a whole second.
  • The times must increase. Out-of-order times are reported under Parts and connections.
  • The lab's run stops at 8 ms, so only the first commands in each table are used. Typing the whole table is still good practice.

Why these tables work

Each source switches at a different rate, doubling from one to the next, exactly like the digits of a binary counter. So as time passes, the inputs step through every combination: 00, 01, 10, 11 for two inputs within 4 ms, and all eight three-input combinations within 4 ms too. That's what lets you read a complete truth table off one run.

Timing diagrams and logic lanes

When the circuit has digital parts, the Q Circuits plot draws logic lanes: each probed signal gets its own 0/1 strip, top to bottom in the order you placed the probes. The handout wants inputs first and the output last, so the lab checks your probe order. If it's wrong, remove the probes and place them again.

The handout names inputs A, B, C and the output Q (or QBAR when inverted) because that's the usual convention in truth tables and Boolean expressions.

Section 10.6

Labs 10C to 10E: three inputs

AND, NAND, and a NAND followed by an inverter.

Labs 10C to 10E add a third input, C, driven by DSTM3.

Select a part.

In Q Circuits

  1. 10C: start from your 10A circuit and rename it LAB 10C. Delete the 7432 and place a Gate3 set to 7411 AND, named U1A.
  2. Move DSTM2 and its wire so it meets the middle input. Add DSTM3 below with the handout's commands (it changes every 0.5m), wire it to the bottom input, and name that wire C. Keep Q on the output.
  3. Same transient settings. Probe A, B, C, then Q.
  4. 10D: start from 10C, change U1A's Device to 7410 NAND, and rename Q to QBAR. Probe A, B, C, then QBAR.
  5. 10E: start from 10D. Place a NOT (7404), U2A, to the right; wire QBAR to its input; run a short wire from its output and name it Q. Probe A, B, C, QBAR, then Q.
  6. For each, run, answer the questions under Your readings, and press Check my work.

10E: two inversions cancel

A NOT after a NAND undoes the NAND's built-in inversion: NOT (NOT (A · B · C)) = A · B · C. The 10E output lane matches 10C's exactly, so the pair behaves like a single 7411. The exercise asks you to name that part number.

Why build it the long way? Real designers often have spare NAND gates on a board. Knowing that NAND plus NOT equals AND lets them use what's there instead of adding a chip.

Glossary

Bit
A single 0 or 1.
Logic gate
A circuit that makes a 0/1 output from 0/1 inputs by a fixed rule.
Truth table
The output for every input combination.
Boolean expression
A formula for a logic function.
Complement
The opposite level; what a NOT gate produces.

A source defined by times and levels.
