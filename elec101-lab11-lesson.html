Section 11.1

Memory and clocks

From combinational to sequential logic, and the DigClock source.

Every Lab 10 circuit was combinational logic: the output depended only on the inputs at that moment. Lab 11 adds sequential logic, circuits with memory, whose output also depends on what happened before. Memory is what lets a computer count, store numbers and follow steps in order.

Clocks

Sequential circuits usually act in step with a clock: a signal that switches back and forth at a steady rate. For repeating inputs the handout switches from STIM1 to the DigClock source, which needs just five settings instead of a long command list.

DigClock settings (Selected part panel)
SettingMeaning
OFFTIMETime spent at STARTVAL in each cycle
ONTIMETime spent at OPPVAL in each cycle. Period = ONTIME + OFFTIME
DELAYExtra time at STARTVAL before the first cycle
STARTVALThe level the clock starts at (0 or 1)
OPPVALThe other level

With STARTVAL 0 and OPPVAL 1, equal ONTIME and OFFTIME give a 50% duty cycle; OFFTIME = 3 × ONTIME gives 25%. With STARTVAL 1 and OPPVAL 0 the clock starts high, which matters when a circuit acts on the clock's falling edge.

Names in the handout

The handout mixes the names DSTM and DSTIM for the sources. Use the names the Q Circuits tasks give (DSTM1, DSTM2 …, and Clear); the checks look for those.

Section 11.2

Lab 11A: XOR

An exclusive-OR gate driven by two clocks.

Open 11A · XOR with clock inputs. An XOR gate outputs 1 when its inputs differ, so it's a one-bit difference detector. Because DSTM2 runs twice as fast as DSTM1, every input combination appears within 0.4 ms.

Select a clock or the gate.

  1. Type LAB 11A in the circuit name box.
  2. Place a Gate, set its Device to 7486 XOR, and name it U1A. (The handout's text says 7432 in places; the part is the 7486.)
  3. Place two DigClock sources: DSTM1 above-left (OFFTIME .2m, ONTIME .2m) and DSTM2 below-left (OFFTIME .1m, ONTIME .1m). Leave DELAY 0, STARTVAL 0, OPPVAL 1.
  4. Wire DSTM1 to the top input and DSTM2 to the bottom input, and run a short wire from the output.
  5. Net aliases: A on the DSTM1 wire, B on the DSTM2 wire, Q at the end of the output wire.
  6. In the Analysis panel choose Transient: Stop time .5m, Time step 1u.
  7. Probe A, B, then Q. Run it, fill in the truth table, and press Check my work.

Build it in Q Circuits

  1. Type LAB 11B in the circuit name box.
  2. Place two Gate parts, U1A and U1B, both 7400 NAND, U1B below U1A.
  3. Place DigClock DSTM1 at U1A's top input: OFFTIME 75u, ONTIME 75u, STARTVAL 1, OPPVAL 0. Place DSTM2 at U1B's bottom input: OFFTIME .15m, ONTIME .15m, STARTVAL 0, OPPVAL 1.
  4. Run a wire from each output to the right. Name them Q (U1A) and QBAR (U1B), and name the input wires SBAR and RBAR.
  5. Cross-couple the gates: Q to U1B's top input, and QBAR to U1A's bottom input. The handout draws diagonals; Q Circuits wires are right-angled, so route them around as in the drawing above. Where they cross there must be no dot.
  6. In the Analysis panel choose Transient: Stop time 0.5m, Time step 1u.
  7. Probe SBAR, RBAR, Q, then QBAR. Run it, answer the questions, and press Check my work.

About the unknown stretches. Real gates are never exactly equally fast, so a real latch leaving the forbidden state does settle one way or the other, but you can't predict which. Q Circuits gives its gates slightly different delays for the same reason, so your run will show a definite value there. Don't design circuits that rely on it.

Section 11.4

Flip-flops and the 7473

Edge-triggered memory, the JK table, clear, and initialization.

A flip-flop is a one-bit memory that changes only at a clock edge. The 7473 is a JK flip-flop. Inside, it's a master-slave flip-flop: one latch (the master) reads J and K while the clock is high, and a second (the slave) copies the result to Q when the clock falls.

JK flip-flop at a falling clock edge
JKQ after the edgeName
00Q (unchanged)Hold
101Set
010Reset
11Q̅ (opposite)Toggle

Reading the symbol

  • Triangle on CLK: an edge-triggered input. The bubble in front of it means the falling edge (1 to 0).
  • Bubble on CLR: Clear is active-low. While it's 0, Q is forced to 0 regardless of the clock.
  • Q̅ is always the opposite of Q. You can leave it unconnected.

Starting in a known state

A real flip-flop powers up in an unpredictable state, which a simulator shows as the unknown state (X). The handout sets Initialize all flip-flops to: 0. In Q Circuits the same choice is Initialize flip-flops to in the Analysis panel, under the transient settings. Labs 11C and 11D check that it's 0.

Section 11.5

Lab 11C: JK flip-flop

Trace Q edge by edge through clocks and a clear line.

Open 11C · JK flip-flop. Three clocks and a clear line exercise every row of the JK table.

Select a source or the flip-flop.

  1. Type LAB 11C in the circuit name box.
  2. Place a 7473 and name it U1A.
  3. Place three DigClocks on the left: DSTM1 to J (OFFTIME 2.5m, ONTIME 2.5m, STARTVAL 0, OPPVAL 1); DSTM2 to CLK (.75m, .75m, STARTVAL 1, OPPVAL 0); DSTM3 to K (4.5m, 4.5m, STARTVAL 0, OPPVAL 1).
  4. Below them place a STIM1, name it Clear, wire it to CLR, and give it the commands 0s 1; 2.2m 0; 2.3m 1; 7.9m 0; 8.6m 1.
  5. Run a short wire from Q. Net aliases: J, Clock, K, Clear on the input wires and Q on the output.
  6. In the Analysis panel choose Transient: Stop time 10m, Time step 0.1m, and set Initialize flip-flops to 0.
  7. Probe Clear, Clock, J, K, then Q. Run it, read Q at the times asked, and press Check my work.

How to read Q at a given time

  1. Find the last falling clock edge before that time.
  2. Look at J and K while the clock was high just before it, and apply the JK table.
  3. Check Clear: if it's 0 at your time, or dropped to 0 since that edge, Q is 0.

Try it with the diagram, then confirm with your Q Circuits run.

Section 11.6

Lab 11D: synchronous counter

Four flip-flops and two AND gates that count in binary.

Open 11D · Synchronous counter. Four flip-flops and two AND gates make a counter that steps through binary numbers, one per clock pulse.

Counting in binary

Read Q3 Q2 Q1 Q0 as a 4-bit number, Q3 on the left. Counting up, each bit flips when all the bits to its right are 1:

  • Q0 flips every count.
  • Q1 flips when Q0 is 1.
  • Q2 flips when Q0 and Q1 are both 1.
  • Q3 flips when Q0, Q1 and Q2 are all 1.

A JK flip-flop with J = K = 1 toggles, and with J = K = 0 holds. So each flip-flop's J and K just need the “flip now” condition, which the AND gates provide. All four share one clock, so they change together: a synchronous counter.

MOD 8 or MOD 16? The handout calls this a MOD 8 counter, but four flip-flops have 2⁴ = 16 states and count 0 to 15: it's MOD 16 (modulus 16). The exercise asks for the highest count, so you'll see this for yourself.

Build it in Q Circuits

  1. Type LAB 11D in the circuit name box.
  2. Place four 7473s, U1A, U1B, U2A, U2B, left to right, and two Gates, U3A and U3B, set to 7408 AND, above them.
  3. Place a $D_HI (logic 1) and wire it to U1A's J and K. Wire every CLR to the same logic 1 line.
  4. Place a DigClock, DSTM1: OFFTIME 1m, ONTIME 1m, STARTVAL 1, OPPVAL 0. Name its wire Clock and run it to all four CLK inputs. Where it crosses other wires there must be no dot.
  5. Name the Q outputs Q0 (U1A), Q1 (U1B), Q2 (U2A) and Q3 (U2B). Leave the Q̅ outputs open.
  6. Wire Q0 to U1B's J and K. U3A takes Q1 and Q0; its output goes to U2A's J and K. U3B takes Q2 and U3A's output; its output goes to U2B's J and K.
  7. Transient: Stop time 32m, Time step 0.1m, Initialize flip-flops to 0.
  8. Probe Clock, Q3, Q2, Q1, then Q0. Run it, read Q3 Q2 Q1 Q0 as a binary number for the questions, and press Check my work.

Glossary

Dotted-underlined words in the lesson show their definition when you point at, tap or tab to them. The full course glossary (opens in a new tab) is searchable.

Sequential logic
Logic with memory.
Clock / DigClock
A steady on-off signal, and the source that makes it.
Active-low
An input that acts when it is 0.
Latch
Memory that responds immediately, with no clock.
Forbidden state
SBAR = RBAR = 0 in a NAND latch.
Flip-flop
Memory that changes only at a clock edge.
JK flip-flop
Hold, set, reset or toggle, chosen by J and K.
Falling edge
A 1-to-0 change, when the 7473 acts.
Clear
Forces Q to 0; active-low on the 7473.
Synchronous counter
A counter whose flip-flops share one clock.
Modulus
The number of states a counter cycles through.
